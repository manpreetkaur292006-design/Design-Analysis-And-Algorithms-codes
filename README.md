# Design and Analysis of Algorithms

A collection of **Design and Analysis of Algorithms (DAA)** programs implemented in Python for learning algorithm design, time complexity, and performance analysis.

## 📌 Topics Covered

* Linear Search — `O(n)`
* Binary Search — `O(log n)`
* Bubble Sort — `O(n²)`
* Insertion Sort — `O(n²)`
* Recursive & Iterative Algorithms
* Runtime and Complexity Analysis
* Algorithm Performance Comparison

## 🛠️ Technology

* Python 3

## 🎯 Purpose

This repository contains DAA laboratory programs for practicing **algorithm implementation, complexity analysis, and performance comparison**.
