2. 2.7 Optimization Technique Reflection Report

You are developing a reflection and recommendation module for an optimization system.

The system must compare three algorithm design techniques:

Divide-and-Conquer

Greedy Algorithm

Dynamic Programming

For each given problem scenario, recommend the most suitable technique and provide a short reason.

Use the following scenario codes:

TASK_SORTING

MEETING_SCHEDULE

RESOURCE_FRACTION

JOB_PROFIT

ZERO_ONE_KNAPSACK

SEQUENCE_MATCHING

Recommendation rules:

TASK_SORTING uses Divide-and-Conquer.

MEETING_SCHEDULE uses Greedy.

RESOURCE_FRACTION uses Greedy.

JOB_PROFIT uses Greedy.

ZERO_ONE_KNAPSACK uses Dynamic Programming.

SEQUENCE_MATCHING uses Dynamic Programming.

The program must also display a general comparison of the three techniques and a final conclusion.

Input Format

First line: An integer n representing the number of scenarios.

Next n lines: Each line contains one scenario code.

Output Format

First print:

Optimization Technique Reflection Report

Then print the technique comparison.

Then print scenario-wise recommendations.

Finally, print the summary and conclusion.

Constraints

1 <= n <= 20

Scenario code will be one of the valid codes listed in the problem statement.

The input-reading and output-handling functionality is already implemented in the hidden Wrapper Code. Students should not write input(), main(), or additional input-handling statements in their submissions.
