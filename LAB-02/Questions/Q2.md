1. 2.2 Activity Selection for Meeting Scheduling
Coding
MEDIUM
5 marks
You are developing a meeting scheduling system for a company.

Each meeting activity has an activity ID, start time and finish time.

The goal is to select the maximum number of non-overlapping meetings that can be scheduled in one room.

Use the Greedy Activity Selection approach.

Always select activities based on earliest finish time.

If two activities have the same finish time, choose the one with the smaller start time first.

If both finish time and start time are the same, choose the lexicographically smaller activity ID first.

A meeting can be selected if its start time is greater than or equal to the finish time of the last selected meeting.

Display the selected activities along with a short justification.

Input Format

First line: An integer n representing the number of activities.

Next n lines: Each line contains activity ID, start time and finish time.

Input activity format:

activity_id start_time finish_time

Output Format

First print:

Activity Selection Report

Then print:

Selected Activities

Then print the heading:

Activity Start Finish Reason

After that, print each selected activity with its reason.

Finally, print the total number of selected activities and the greedy justification.

Constraints

1 <= n <= 100

Activity ID contains no spaces.

0 <= start_time < finish_time <= 100000

All activity IDs are unique.
