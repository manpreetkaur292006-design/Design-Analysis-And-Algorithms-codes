## Merge Sort and Quick Sort for Task Prioritization

You are developing a task prioritization module for a resource allocation system.
Each task has a task ID and a priority value.
Tasks with higher priority must come first.
If two tasks have the same priority, the task with the lexicographically smaller task ID must come first.
Implement task sorting using both Merge Sort and Quick Sort.
For performance comparison, count the number of element comparisons made by each algorithm.
For Quick Sort, always use the last element as the pivot.
After sorting, display the sorted task list generated by Merge Sort and Quick Sort.
Finally, display which algorithm used fewer comparisons.
If both algorithms use the same number of comparisons, print Both Equal.

Input Format
First line: An integer n representing the number of tasks.
Next n lines: Each line contains task ID and priority.
Input task format:
task_id priority
Output Format
First print:
Task Prioritization Report
Then print:
Merge Sort Result
After that, print the sorted tasks using Merge Sort.
Then print the Merge Sort comparison count.
Then print:

Quick Sort Result
After that, print the sorted tasks using Quick Sort.
Then print the Quick Sort comparison count.
Finally, print the better algorithm based on fewer comparisons.
Constraints

1 <= n <= 100
Task ID contains no spaces.
Task IDs are unique.
1 <= priority <= 100
Quick Sort must use the last element as pivot.
