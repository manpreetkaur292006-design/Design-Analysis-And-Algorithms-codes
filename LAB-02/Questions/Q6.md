1. 2.6 Longest Common Subsequence with Complexity Observation

You are developing a sequence matching module for an optimization system.

Given two strings, find their Longest Common Subsequence using Dynamic Programming.

A subsequence is a sequence that appears in the same relative order, but not necessarily continuously.

The program must display:

Length of the Longest Common Subsequence

The Longest Common Subsequence string

DP table size

Number of DP cell computations

Time complexity

Space complexity

If no common subsequence exists, display None as the LCS string.

For auto-evaluation, use deterministic DP cell computation count.

DP cell computation count is:

length of first string × length of second string

If multiple LCS strings are possible, reconstruct the LCS using this rule:

If characters match, include the character and move diagonally.

If characters do not match and upper cell value is greater than or equal to left cell value, move upward.

Otherwise, move left.

Input Format

First line: First string.

Second line: Second string.

Output Format

First print:

LCS Analysis Report

Then print the LCS length, LCS string, DP table size, DP cell computations and complexity observation.

Constraints

1 <= length of each string <= 100

Strings contain uppercase English letters only.
