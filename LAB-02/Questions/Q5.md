1. 2.5 0/1 Knapsack using Dynamic Programming Zosima Problem Details

You are developing a resource allocation system.

Each item has an item ID, value and weight.

The system has a knapsack with limited capacity.

Your task is to compare two approaches:

0/1 Knapsack using Dynamic Programming

Fractional Knapsack using Greedy approach

In 0/1 Knapsack, an item can either be selected completely or not selected at all.

In Fractional Knapsack, fractions of items are allowed.

For 0/1 Knapsack, use Dynamic Programming to calculate the maximum possible value.

For Fractional Knapsack, select items based on highest value-to-weight ratio.

If two items have the same value-to-weight ratio, select the item with the lexicographically smaller item ID first.

Display selected items for both approaches, their total values, total weights and the final comparison.

For 0/1 Knapsack, display selected items in their original input order.

For Fractional Knapsack, display selected items in the order in which they are selected.

All Fractional Knapsack values must be displayed with exactly 2 decimal places.

Input Format

First line: Two integers n and capacity, where n is the number of items.

Next n lines: Each line contains item ID, value and weight.

Input item format:

item_id value weight

Output Format

First print:

Knapsack Comparison Report

Then print the 0/1 Knapsack selected items and result.

Then print the Fractional Knapsack selected items and result.

Finally, print the difference, better result and justification.

Constraints

1 <= n <= 100

1 <= capacity <= 1000

Item ID contains no spaces.

Item IDs are unique.

1 <= value <= 100000

1 <= weight <= capacity
