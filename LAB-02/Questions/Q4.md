2. 2.4 Smart Resource Allocation & Optimization System

You are developing a job scheduling system for a company.

Each job has a job ID, deadline and profit.

Each job takes exactly one time slot to complete.

A job can be scheduled only if it is completed on or before its deadline.

Your task is to schedule jobs in such a way that the total profit is maximized.

Use the Greedy Job Sequencing with Deadlines approach.

Jobs must be considered in descending order of profit.

If two jobs have the same profit, consider the job with the smaller deadline first.

If profit and deadline are both same, consider the lexicographically smaller job ID first.

Each selected job must be assigned to the latest available slot on or before its deadline.

Finally, display the scheduled job sequence in increasing order of time slot.

Input Format

First line: An integer n representing the number of jobs.

Next n lines: Each line contains job ID, deadline and profit.

Input job format:

job_id deadline profit

Output Format

First print:

Job Sequencing Report

Then print:

Scheduled Jobs

Then print the heading:

Slot Job Profit

After that, print each scheduled job in increasing order of slot number.

Finally, print the total number of scheduled jobs, total profit and scheduling strategy.

Constraints

1 <= n <= 100

Job ID contains no spaces.

Job IDs are unique.

1 <= deadline <= 100

1 <= profit <= 100000

Each job takes exactly one time slot.
