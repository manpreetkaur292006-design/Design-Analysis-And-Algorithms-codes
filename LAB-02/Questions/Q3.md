2. 2.3 Fractional Knapsack for Optimal Resource Allocation
Coding
MEDIUM
5 marks
You are developing an optimal resource allocation system.

Each item has an item ID, value and weight.

The system has a knapsack with limited capacity.

Your task is to select items in such a way that the maximum possible value is achieved.

Fractions of items are allowed.

Use the Fractional Knapsack Greedy approach.

Items must be selected based on highest value-to-weight ratio.

If two items have the same value-to-weight ratio, select the item with the lexicographically smaller item ID first.

For each selected item, display the selected fraction and profit obtained from that item.

All fraction, profit and weight values must be displayed with exactly 2 decimal places.

Input Format

First line: Two values n and capacity, where n is the number of items.

Next n lines: Each line contains item ID, value and weight.

Input item format:

item_id value weight

Output Format

First print:

Fractional Knapsack Report

Then print:

Selected Items

Then print the heading:

Item Value Weight Fraction Profit

After that, print each selected item in the order in which it is selected.

Then print the maximum profit and total weight used.

Finally, print the selection strategy.

Constraints

1 <= n <= 100

1 <= capacity <= 100000

Item ID contains no spaces.

1 <= value <= 100000

1 <= weight <= 100000

Fractions of items are allowed.
